# Basic Network Scanning with Nmap

## Objective

The objective of this task is to perform a basic network scan using Nmap to identify open ports and running services on a local machine. This helps understand how Nmap discovers network services and why identifying open ports is important for security.

---

## Tool Used

- Nmap
- Python 3 HTTP Server
- Linux (Ubuntu VM)

---

## Commands Used

### Start the Python HTTP Server

```bash
python3 -m http.server 8000
```

### Verify IP Address

```bash
ifconfig
```

IP Address Used:

```
10.0.2.15
```

### Scan the Server

```bash
nmap -sV 10.0.2.15 -p 8000
```

### Save the Scan Results

```bash
nmap -sV 10.0.2.15 -p 8000 > nmap_scan_results.txt
```

---

## Scan Results

The Nmap scan detected an open HTTP service running on port 8000.

| Port | State | Service | Description |
|------|-------|---------|-------------|
| 8000 | Open | HTTP | Python HTTP Server running locally and accepting HTTP connections. |

---

## Significance of the Open Port

- **Port 8000 (HTTP):**
  - Used by the Python Simple HTTP Server.
  - Allows web clients to connect and access files served by the server.
  - Open ports indicate active services that should be monitored and secured to prevent unauthorized access.

This task demonstrated how to use Nmap to discover open ports and identify running services on a local machine. The scan successfully detected the Python HTTP Server running on port 8000.
